## The remote-work track and what the organization did about it

Remote work is the honest answer to the wage question in this county, so the organization trains for it. Then graduates discover that **their home connection will not carry a workday** — dropped calls, failed uploads, a metered link that an eight-hour VPN session makes expensive.

So Black Mountain built **workstations in its own building**, on a good connection, and graduates come in to do their remote jobs from a room in Whitesburg.

It works. It is also worth naming what has happened: **a training program has quietly become a co-working facility**, funded as workforce development, providing infrastructure the market and the public sector did not. Nobody planned it, no funder line item describes it, and if the organization's grant ended the graduates' jobs would end with it.

## Which of these should become its own file first

**The workstation facility.** It is currently invisible — not in the program list above as its own item, funded as part of remote-work training, and carrying employment that would stop without it. ## A note on reciprocity

The healthcare track and [the clinic's clinical placements](../synthetic-cumberland-gap-health-cooperative/programs.md) are **one program run by two organizations**. Black Mountain cannot train medical assistants without placement sites; the clinic cannot staff itself without a local pipeline. Each appears in the other's program list.

If you are aggregating program counts across this collection, **this activity will be double-counted** unless something distinguishes a jointly-run program from an independent one. The `partners_with` edge records that a relationship exists; it does not record that these two program entries are the same program. That is a modelling gap worth noting.
