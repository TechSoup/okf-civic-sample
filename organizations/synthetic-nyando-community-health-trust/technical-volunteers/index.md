# Technical volunteers

**⚠ Synthetic — fabricated data. And note that this bundle's [verification returned insufficient evidence](../verification.md).**

A bundle with two kinds of thing:

- [constraints](constraints.md) — **the org's own** rules for technology volunteers. The org edits this; an agent scoping a project must honor it.
- **Requests** — one file per project, each a draft the org owns and can post:
  - [data-back-to-the-source](data-back-to-the-source.md) — get the organization's own data back out of the national system so promoters and supervisors can use it, without adding a shilling to what promoters spend.

**Method:** to turn this bundle into a request, an agent reads the org's [README](../../../README.md), [technology](../technology/index.md) (inventory + capability), and [constraints](constraints.md), then frames a project grounded in the org's actual gaps — and marks it a draft the org edits and blesses before anything goes out.

## What a scoping agent must not do here

**Do not propose to build this organization a data system.** It has one, and it is better than anything else in this collection: 142 offline-first mobile collectors, 9,600 registered households, twelve years of continuous monthly reporting into a national health information system. See [inventory](../technology/inventory.md).

An agent reading only the automated assessment — which scores this organization **very low digital maturity**, the lowest of the fifteen — will conclude the opposite and recommend a CRM, cloud adoption, and digital capacity building. That recommendation set is not merely unhelpful. It would insult the people who built the best field data operation in the collection, and it is exactly what a web-signal-based assessment produces for a rural, offline, non-Anglophone organization. See [capability](../technology/capability.md).

**Two things a good scoping agent should notice instead, neither of which the organization put at the top of its ask:**

1. **The promoters are paying for the sync.** Mobile data and airtime for required reporting come out of stipends. Nobody has measured how much. Measuring it takes a week, needs no technology, and would be the single most valuable output any volunteer could produce here.
2. **The data goes up and does not come back.** That is the request below, and it is genuinely the organization's stated need.

Any project here is measured partly on whether it increases or decreases what promoters spend. That is in [constraints](constraints.md) as a hard test.
