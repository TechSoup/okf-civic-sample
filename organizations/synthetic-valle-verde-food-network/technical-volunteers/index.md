# Technical volunteers

**⚠ Synthetic — fabricated data.**

A bundle with two kinds of thing:

- [constraints](constraints.md) — **the org's own** rules and preferences for volunteers. The org edits this; an agent scoping a project must honor it.
- **Requests** — one file per project, each a draft the org owns and can post:
  - [offline-route-capture](offline-route-capture.md) — capture route data on a truck with no signal, and stop finding out about a demand spike two weeks late.

**Method:** to turn this bundle into a request, an agent reads the org's [README](../../../README.md), [technology](../technology/index.md) (inventory + capability), and [constraints](constraints.md), then frames a project grounded in the org's actual gaps — and marks it a draft the org edits and blesses before anything goes out. An org can point its own AI at this bundle and ask, e.g., *"why did the tablets fail and what would work instead,"* and get back something like the request below.

**Read the inventory before the request.** This organization has already tried the obvious version of this project. Four tablets were acquired in 2021 for exactly this purpose and abandoned in six weeks because the software required a connection to save. A volunteer who proposes the same thing again will waste everyone's season. The request below starts from that failure.
