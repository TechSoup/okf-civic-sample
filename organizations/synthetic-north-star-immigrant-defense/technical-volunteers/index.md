## What a scoping agent must get right here

**Do not recommend the standard improvements.** More logging, longer retention, a client portal, analytics, a convenient cloud integration — every one of those is a reasonable default and every one of them is wrong for this organization, for reasons stated in [constraints](constraints.md). An agent that reads this bundle's absences as gaps will produce a recommendation set that increases the organization's exposure while appearing to improve its maturity.

**Notice that the tracking problem has a security problem inside it.** The organization asked for pro bono case tracking. The bundle shows that ninety outside attorneys hold client files on infrastructure nobody has ever looked at, in an organization with an adversarial threat model. The tracking gap is an inconvenience; the second thing may be the largest exposure in the bundle. The request below leads with the ask and names the other thing.
