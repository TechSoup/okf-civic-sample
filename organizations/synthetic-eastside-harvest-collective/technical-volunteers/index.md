# Technical volunteers

**⚠ Synthetic — fabricated data.**

A bundle with two kinds of thing:

- [constraints](constraints.md) — **the org's own** rules and preferences for volunteers. The org edits this; an agent scoping a project must honor it.
- **Requests** — one file per project, each a draft the org owns and can post:
  - [harvest-distribution-dashboard](harvest-distribution-dashboard.md) — get pounds grown and pounds distributed out of paper notebooks and into something a funder report can read.

**Method:** to turn this bundle into a request, an agent reads the org's [README](../../../README.md), [technology](../technology/index.md) (inventory + capability), and [constraints](constraints.md), then frames a project grounded in the org's actual gaps — and marks it a draft the org edits and blesses before anything goes out. An org can point its own AI at this bundle and ask, e.g., *"suggest a project that would stop our farm managers spending Sunday nights typing up notebooks,"* and get back something like the request below.
