# Programs & services

**⚠ Synthetic — fabricated data.**

*The list below is **derived** (simulated) from public materials; a real organization would confirm and replace it with its own description.*

Riverbend Air's programming is one loop: measure, publish, intervene.

- **Community air-monitoring network** — 31 low-cost particulate sensors hosted on residents' homes, reading continuously, feeding a public map. The technical core of everything else. See [inventory](technology/inventory.md) — for this organization the inventory *is* the program description.
- **Permit and regulatory advocacy** — technical comments on air-permit applications and renewals, using the network's own data. Roughly six to ten filings a year.
- **Asthma outreach with clinics** — a partnership with two neighborhood clinics: when sensors register a sustained spike, families with asthma-diagnosed children get an advisory. This is the program that turns a number into an action, and it is also the one with the hardest data-protection questions.
- **Youth science corps** — 12–16 young people a year, ages 14–18, trained to read the data and testify from it. Several have presented at public hearings.
- **Truck-route documentation** — volunteer counts of heavy-vehicle traffic on residential streets, paired with sensor readings, used to support re-routing requests.

*(Pollution monitoring and abatement advocacy is the activity behind its [C20](../../_shared/ntee/C20.md) classification; the conservation framing of the corridor work is why it also carries [C30](../../_shared/ntee/C30.md).)*

The **asthma-outreach partnership** should become its own file first if this grows into a folder — it involves a second party, health information, and a notification pathway with real consequences if it fails silently, none of which the other programs do.
