# Examples

This directory holds one generated output per organization: each
organization's frontmatter re-expressed as a [Philanthropy Data
Commons](https://philanthropydatacommons.org/base-fields-list/) (PDC)
Application Form document.

Every file here is generated, not authored. Nothing in this directory
should be hand-edited — delete a file and regenerate it instead.

## Where these come from

Each `<org>_pdc.json` file is the output of:

```
python3 scripts/generate_mapped_json.py <org_folder> pdc
```

run from the repository root, where `<org_folder>` is one of the fifteen
folder names under `organizations/`. See
[`scripts/README.md`](../scripts/README.md) for how the script and the
`pdc` mapping folder (`scripts/mappings/pdc/map.md` and
`definition.json`) work.

**⚠ The `pdc` mapping is a guess, not a verified schema.**
`scripts/mappings/pdc/map.md` was generated by Claude Code for testing
purposes, pairing each frontmatter property with a PDC field code by
reading PDC's public field list. It has not been reviewed by anyone who
owns the PDC schema. Treat these files as a demonstration of what the
mapping *mechanism* produces, not as PDC-conformant data.

**⚠ Synthetic organizations.** As with the rest of this repository, every
organization named here is fabricated — see the root
[README.md](../README.md) for why. Every value in these files carries
that same fiction; none of it describes a real nonprofit.

## Regenerating

To rebuild one file:

```
python3 scripts/generate_mapped_json.py <org_folder> pdc
```

To rebuild all fifteen from the repository root:

```
for org in organizations/*/; do
  python3 scripts/generate_mapped_json.py "$(basename "$org")" pdc
done
```

Each run reads only that organization's own markdown frontmatter and the
`pdc` mapping files — there is no network access or external lookup
involved.
