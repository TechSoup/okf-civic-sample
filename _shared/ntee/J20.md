# J20 — Employment procurement assistance

**A shared classification node.** Organizations carry this code in optional `x-civic.ntee`; the Members list below is generated from that key by `scripts/build_hubs.py`. NTEE is a US-only layer, so it reaches twelve of the fifteen.

## What this code means

**Employment procurement assistance** — the work of getting someone into a job: employer relationships, placement, and the negotiation around a specific person's hiring. Distinct from [J22](J22.md) (job training), which describes teaching the skills.

*Title given as commonly published; confirm against the current NTEE-CC listing — this part of the J range has near-neighbours with overlapping names. **NTEE is a US IRS vocabulary** — see [index](index.md).*

## The member that is missing from this hub is the interesting one

Two of the three US workforce organizations carry this code. The one that does not — [Black Mountain Workforce Partnership](../../organizations/synthetic-black-mountain-workforce-partnership/README.md) — is arguably the one doing the most placement work, because it **refuses to run a training track without an employer commitment arranged before the cohort starts.**

Placement is not an addition to its programme; it is a precondition of its programme existing. And it does not carry the code.

Meanwhile [Crescent City Career Lab](../../organizations/synthetic-crescent-city-career-lab/README.md) carries it and reports "about thirty employer partners," a figure that mixes employers who hire from every cohort with employers who took one graduate in 2023, because **"employer partner" has no definition and a grant application asked for a count.**

So in this hub: **the organization with the most rigorous employer practice is absent, and the organization with the loosest definition of an employer relationship is present.** Neither is misreporting. It is what happens when codes are self-assigned and a count is requested without a definition.

**A useful caution about secondary NTEE codes as a signal.** They tell you how an organization has learned to describe itself. It does not tell you what the organization does more of.
