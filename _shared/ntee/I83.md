## What this code means

**Public interest law** — litigation and legal advocacy aimed at systemic outcomes rather than at an individual client's matter. Distinct from [I80](I80.md) (legal services), which describes direct representation.

*Title given as commonly published; confirm against the current NTEE-CC listing. **NTEE is a US IRS vocabulary** — see [index](index.md).*

## The distinction between direct service and impact work is real, and it is hard to encode

One organization here carries this code alongside [I80](I80.md), and the pairing describes something true: it does mostly individual representation and some deliberate precedent-seeking work.

But the boundary is not clean anywhere in practice. A removal-defense case taken partly because it presents a good legal question is both things at once. **Every organization that does volume representation eventually picks cases for reasons beyond the client in front of it**, and the code that captures this is carried by exactly one of the three legal-aid organizations in this collection — not because the other two never do it, but because of how each described itself.

**Worth treating a secondary `x-civic.ntee` code as a statement about self-description rather than about activity.** In a corpus assembled from organizations' own filings, that is what these codes are.
